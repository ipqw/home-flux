# Кластер home

k3s на домашней машине (`ipqw-server`, Debian 13, 192.168.0.110).
Публичного адреса нет — дом за NAT. Наружу смотрит только VPS.

    браузер → 443 VPS → xray (SNI) → traefik VPS → 10.8.0.2:80 → traefik home → под

Доступ к API: `kubectl --context home` из локальной сети (6443 открыт только
для 192.168.0.0/24) и через туннель WireGuard с VPS (10.8.0.0/24).

Сертификаты выпускает cert-manager на **vps** — здесь его нет намеренно.
